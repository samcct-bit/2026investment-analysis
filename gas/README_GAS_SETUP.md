## 📌 步驟 1：建立 Google 試算表表格

1. 前往 [Google Sheets](https://sheets.new) 建立新試算表，命名為「**台積電智慧投資加碼監控**」。
2. 在工作表中精準貼上以下公式與內容（請直接複製）：

| 儲存格 | 欄位名稱 | 填入內容 / 公式 | 說明 |
| :--- | :--- | :--- | :--- |
| **A1** | 股票代號 | `代碼` | 表頭 |
| **A2** | 台積電代號 | `TPE:2330` | 監控目標：台積電 |
| **B2** | 目前股價 | `=GOOGLEFINANCE(A2, "price")` | 自動抓取台積電最新價格 |
| **C2** | 20日均線 | `=AVERAGE(INDEX(GOOGLEFINANCE(A2, "price", TODAY()-35, TODAY()), 0, 2))` | 台積電 20MA (月線) |
| **D2** | 狀態判斷 | `=IF(ISNUMBER(B2), IF(B2<C2, "跌破月線", "觀望"), "讀取中")` | 台積電狀態 |
| **E2** | 最後通知 | *(留空)* | 由程式自動寫入今日日期，防重複發信 |
| **A3** | 大盤指標代號 | `TPE:0050` | 大盤趨勢參考標的 (0050) |
| **B3** | 目前股價 | `=GOOGLEFINANCE(A3, "price")` | 抓取大盤指數 / 0050 最新價 |
| **C3** | 20日均線 | `=AVERAGE(INDEX(GOOGLEFINANCE(A3, "price", TODAY()-35, TODAY()), 0, 2))` | 大盤 20MA |
| **D3** | 狀態判斷 | `=IF(ISNUMBER(B3), IF(B3<C3, "大盤走弱", "大盤偏多"), "讀取中")` | 大盤趨勢狀態 |

## 📌 步驟 2：貼上 Google Apps Script 程式碼

1. 點擊試算表上方選單「**擴充功能**」 ➔ 「**Apps Script**」。
2. 清空既有程式碼，將 [`gas/Code.gs`](file:///d:/antigravity/2026investment-analysis/gas/Code.gs) 的最新程式碼複製並貼入編輯器中。
3. 按下 `Ctrl + S` 或點擊儲存圖示。

---

## 📌 步驟 3：手動測試與首次授權

1. 在編輯器上方執行選單中，選擇 `testCalendarAndEmail` 函式。
2. 點擊「**執行 (▶️)**」。
3. 首次執行會彈出「需要權限」視窗 ➔ 選擇您的 Google 帳號 ➔ 點擊「**進階**」 ➔ 點擊「**前往（不安全）**」 ➔ 點擊「**允許**」（包含 Gmail 發信與日曆讀寫權限）。
4. 檢查您的 **Gmail** 與 **Google 日曆**，確認有收到測試信件與新增的日曆測試行程。

---

## 📌 步驟 4：設定每日收盤自動檢查 (時間驅動觸發器)

1. 點擊 Apps Script 左側「**時鐘圖示 (觸發條件)**」 ➔ 點擊右下角「**+ 新增觸發條件**」。
2. 進行以下選項設定：
   - **選擇您要執行的功能**：`checkMarketAndNotify`
   - **選擇應執行的部署作業**：`Head`
   - **選取活動來源**：`時間驅動`
   - **選取以時間為基準的觸發條件類型**：`日計時器`
   - **選取時間範圍**：`下午 1:00 至 下午 2:00`（台股 13:30 收盤，此時價格與月線最精準）
   - **錯誤通知設定**：`每天通知`
3. 點擊「**儲存**」。
